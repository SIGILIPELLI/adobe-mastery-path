# Adobe Creative Cloud Mastery Path

A free, structured, module-wise Adobe Creative Cloud training program —
entry level to master level, with step-by-step workflow instructions,
keyboard-shortcut cheat sheets, and a hands-on exercise in every module.
Focused on real design/video production skills: Photoshop, Illustrator,
Premiere Pro, After Effects, Lightroom, and InDesign.

**Live site:** https://sigilipelli.github.io/adobe-mastery-path/

## Contents

- **Level 1 · Entry** — Creative Cloud setup & Libraries, Photoshop/Illustrator/Premiere/After Effects basics, cross-app Libraries workflow, brand-kit capstone
- **Level 2 · Intermediate** — deeper Photoshop, Illustrator, and Premiere workflows
- **Level 3 · Advanced** — After Effects motion graphics, Lightroom, InDesign
- **Level 4 · Master** — multi-app production pipelines, color management, client delivery

## Local development

```bash
python3 -m venv .venv
.venv/bin/pip install mkdocs-material
.venv/bin/python -m mkdocs serve
```
