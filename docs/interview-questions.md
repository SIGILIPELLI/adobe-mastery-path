## Level 1 · Entry

### [01 · Creative Cloud Setup, Libraries &amp; Sync](level-1/01-setup-libraries-sync.md)

**Q1.** What is the main role of the Creative Cloud desktop app?

**Answer:** The launcher, updater and sync client for your Adobe apps and assets

The desktop app is not a design tool itself; it installs and updates apps and syncs your assets.

**Q2.** Where do you toggle automatic updates for your Adobe apps?

**Answer:** Creative Cloud desktop app menu &gt; Preferences &gt; Apps &gt; Auto-update

Open the desktop app's menu, go to Preferences &gt; Apps and switch on Auto-update.

**Q3.** What does a Creative Cloud Library hold?

**Answer:** Reusable assets such as colors, character styles, graphics and images that sync across apps

Libraries are containers of reusable assets that sync to Adobe's servers and appear in every app you sign into.

**Q4.** A menu item from a lesson isn't where described in your version. What does the lesson suggest?

**Answer:** Check Help &gt; About for your version and search the in-app Help bar for the command name

Panel positions can shift between versions; the command usually still exists, just relocated.

### [02 · Photoshop Basics](level-1/02-photoshop-basics.md)

**Q5.** Photoshop is best described as which kind of editor?

**Answer:** Raster (pixel-based) editor

Photoshop works on grids of colored pixels, which suits photos and painted artwork.

**Q6.** A panel you need has disappeared from the workspace. Where can you restore it?

**Answer:** The Window menu, e.g. Window &gt; Layers

Every panel lives under the Window menu and can be toggled back on from there.

**Q7.** What is the difference between Opacity and Fill on a layer?

**Answer:** Opacity fades the whole layer including layer styles; Fill fades only the layer's own pixels

Fill leaves layer styles such as a drop shadow at full strength, which is useful for shadow-only or stroke-only effects.

**Q8.** How do you group several selected layers?

**Answer:** Layer &gt; Group Layers (Cmd/Ctrl+G)

Groups act like folders and keep complex files navigable.

### [03 · Illustrator Basics](level-1/03-illustrator-basics.md)

**Q9.** Why can vector artwork scale from a business card to a billboard without losing sharpness?

**Answer:** It is stored as mathematical paths of points and curves

Vector shapes are paths defined mathematically, so they render crisply at any size.

**Q10.** What can a single Illustrator document hold that Photoshop documents cannot in the same way?

**Answer:** Multiple artboards

One file can contain many artboards, such as a logo at three sizes.

**Q11.** Which tool selects and drags individual anchor points within a shape?

**Answer:** Direct Selection tool (A)

The Selection tool moves whole shapes; Direct Selection edits individual anchor points and segments.

**Q12.** What does holding Shift while dragging the Rectangle or Ellipse tool do?

**Answer:** Constrains the shape to a perfect square or circle

Shift constrains proportions so rectangles become squares and ellipses become circles.

### [04 · Premiere Pro Basics](level-1/04-premiere-basics.md)

**Q13.** What does the Source Monitor show?

**Answer:** A clip before it is placed on the timeline, where you can set in/out points

The Program Monitor previews the sequence; the Source Monitor previews raw clips.

**Q14.** A clip shows a red offline warning after you moved the source file. What fixes it?

**Answer:** Right-click the clip and choose Link Media

Imported clips are references to files on disk, so a moved file must be relinked.

**Q15.** Which tool cuts a clip into two at the point you click?

**Answer:** Razor tool (C)

The Razor tool splits a clip so each part can be moved or deleted independently.

**Q16.** What does Ripple Delete (Shift+Delete) do?

**Answer:** Removes a segment and closes the gap it leaves

Ripple Delete removes the selected segment and shifts later clips to close the gap.

### [05 · After Effects Basics](level-1/05-after-effects-basics.md)

**Q17.** What is a composition in After Effects?

**Answer:** Its unit of work, similar to a Premiere sequence but built for layering and animating

A composition (comp) is where layers are stacked and animated.

**Q18.** Which shortcut reveals a selected layer's Opacity property?

**Answer:** T

P is Position, S Scale, R Rotation and T Opacity.

**Q19.** You set one keyframe on a property and nothing else. What happens?

**Answer:** It sets a fixed value with no motion

You need at least two keyframes at different times with different values for any animation.

**Q20.** How do you enable keyframing on a property?

**Answer:** Click the stopwatch icon next to the property name

Clicking the stopwatch turns on keyframing and places the first keyframe at the current time and value.

### [06 · Photoshop Compositing &amp; Retouching](level-1/06-photoshop-compositing-retouching.md)

**Q21.** On a layer mask, what does painting with black do?

**Answer:** Hides that part of the layer without deleting pixels

Black hides, white reveals and gray partially hides, all non-destructively.

**Q22.** You already have an active selection. What does clicking Add Layer Mask do?

**Answer:** Converts the selection into a mask, hiding everything outside it

The selection becomes the mask, so everything outside it is hidden immediately.

**Q23.** An adjustment layer affects which layers?

**Answer:** Layers below it in the stack

Adjustment layers apply to everything beneath them unless clipped to the single layer directly below.

**Q24.** How can you limit an adjustment layer to only the single layer directly beneath it?

**Answer:** Use Layer &gt; Create Clipping Mask

The clipping mask (Alt/Option+Cmd/Ctrl+G) restricts the adjustment to that one layer.

### [07 · Illustrator Vector Workflows](level-1/07-illustrator-vector-workflows.md)

**Q25.** Which Pathfinder operation cuts the topmost shape out of the shapes below it?

**Answer:** Minus Front

Minus Front subtracts the front shape, as when making a crescent from two circles.

**Q26.** Which Pathfinder operation keeps only the area where the selected shapes overlap?

**Answer:** Intersect

Intersect keeps the overlap, such as the lens shape of a Venn diagram.

**Q27.** Where do you open the Pathfinder panel?

**Answer:** Window &gt; Pathfinder

Window &gt; Pathfinder (Shift+Cmd/Ctrl+F9) opens it.

**Q28.** After a Pathfinder operation, what is the result and how can you refine it?

**Answer:** A single new path, refined with the Direct Selection tool

The result is one new path whose points you can adjust with the Direct Selection tool (A).

### [08 · Premiere Editing Workflow](level-1/08-premiere-editing-workflow.md)

**Q29.** A Cross Dissolve shows a red warning triangle. What is the likely cause and fix?

**Answer:** The clip has no spare frames beyond the cut; trim less tightly or shorten the transition

A dissolve needs extra frames (trim handles) on both clips to overlap into.

**Q30.** What does the Auto-Match button in Essential Sound's Loudness section do?

**Answer:** Analyzes the clip and adjusts it toward a target loudness

It is a fast first pass for clips with inconsistent recording levels.

**Q31.** Roughly where should dialogue generally peak, per the lesson?

**Answer:** Around -12 to -6 dB

Dialogue should peak around -12 to -6 dB, never slamming into 0 dB, which causes clipping or distortion.

**Q32.** When is a dissolve the lesson's recommended choice over a hard cut?

**Answer:** Mainly at scene changes or time/location jumps

Use transitions sparingly; a hard cut is still right most of the time.

**Q35.** Where do Library colors appear in Premiere Pro, per the lesson?

**Answer:** In the Essential Graphics panel when editing a graphic or text fill color

Availability can vary by version; if missing, apply the same hex value manually.

**Q36.** What is a good practice when adding swatches to a Library?

**Answer:** Give meaningful names such as Brand Primary

Meaningful names make shared assets easy to find and apply consistently.

## Level 2 · Intermediate

### [01 · Advanced Layers &amp; Smart Objects (Photoshop)](level-2/01-advanced-layers-smart-objects.md)

**Q41.** Why does scaling a Smart Object repeatedly not accumulate blur?

**Answer:** Free Transform scales from the original embedded or linked data, not the last-resampled pixels

The transform is stored as an editable instruction on the container rather than baked into pixels.

**Q42.** What is the difference between Place Embedded and Place Linked?

**Answer:** Embedded stores a full copy inside the .psd; Linked references the external file, keeping the .psd smaller

Linked files stay smaller but depend on the external file remaining in place.

**Q43.** What does Replace Contents do on a Smart Object?

**Answer:** Swaps the source file while keeping existing transforms, filters and position

It is handy for swapping a placeholder photo for a final one late in a layout.

**Q44.** What happens to a filter applied to a Smart Object layer?

**Answer:** It becomes an editable Smart Filter with its own mask

You can reopen its settings or paint on its mask to limit where it applies.

### [02 · Photoshop Color Correction &amp; Grading](level-2/02-photoshop-color-correction.md)

**Q45.** Which Curves shape is the classic contrast boost?

**Answer:** An S-curve: shadows pulled slightly down, highlights pulled slightly up

An S-curve deepens blacks and brightens whites while leaving midtones roughly alone.

**Q46.** How can you remove a blue tint from dark areas using Curves?

**Answer:** Pull the Blue channel curve down in the shadows

Switching to the Blue channel lets you correct the cast without changing overall brightness.

**Q47.** A photo shot under tungsten light looks too orange. What does the lesson suggest in Color Balance?

**Answer:** Select Midtones and move Yellow–Blue toward Blue and Cyan–Red slightly toward Cyan

Shifting midtones toward the missing colors neutralizes the cast.

**Q48.** Why usually leave Preserve Luminosity checked in Color Balance?

**Answer:** So a color fix doesn't also brighten or darken the image

It keeps overall brightness unchanged while only shifting color.

### [03 · Illustrator Advanced Typography](level-2/03-illustrator-advanced-typography.md)

**Q49.** What do Standard Ligatures do?

**Answer:** Join colliding letter pairs such as fi and fl into a single better-fitted glyph

Standard ligatures fix pairs that collide at their default spacing.

**Q50.** How do Old Style figures differ from Lining figures?

**Answer:** Old Style numerals vary in height and blend quietly into text; Lining numerals are all cap-height

Lining figures suit all-caps headlines and aligned number tables.

**Q51.** What can a Paragraph Style do that a Character Style cannot on its own?

**Answer:** Set indents, spacing, alignment and hyphenation for whole paragraphs, and reference a Character Style

One click sets both paragraph settings and the referenced character formatting.

**Q52.** Why might most of the OpenType panel be grayed out?

**Answer:** The font itself doesn't support those features

OpenType features are built into the font file, and small system fonts often lack them.

    ```
    import math, random

    # --- timecode -------------------------------------------------------------
    def to_timecode(frames, fps=24):
        f = frames % fps
        s = frames // fps
        return f"{s // 3600:02d}:{s // 60 % 60:02d}:{s % 60:02d}:{f:02d}"

    def to_dropframe(frames):
        """29.97 fps drop-frame: skip frame numbers 00 and 01 at the start of every minute except every tenth minute."""
        d, m = divmod(frames, 17982)              # frames per 10 minutes
        frames += 18 * d + (2 * ((m - 2) // 1798) if m > 2 else 0)
        f = frames % 30
        s = frames // 30
        return f"{s // 3600:02d}:{s // 60 % 60:02d}:{s % 60:02d};{f:02d}"

    print(to_timecode(90 * 24), to_timecode(24 * 3600 + 5 * 24 + 7), to_dropframe(1800), to_dropframe(17982))

    # --- keyframe interpolation and easing ------------------------------------
    def linear(t): return t
    def ease_in_out(t): return 3 * t ** 2 - 2 * t ** 3            # smoothstep, like Easy Ease
    def ease_out(t): return 1 - (1 - t) ** 3

    def bezier(x1, y1, x2, y2):
        """CSS-style cubic-bezier easing solved with bisection on x."""
        def curve(a, b, t): return 3 * a * (1 - t) ** 2 * t + 3 * b * (1 - t) * t ** 2 + t ** 3
        def ease(x):
            lo, hi = 0.0, 1.0
            for _ in range(40):
                mid = (lo + hi) / 2
                if curve(x1, x2, mid) < x: lo = mid
                else: hi = mid
            return curve(y1, y2, (lo + hi) / 2)
        return ease

    def animate(keys, t, ease=linear):
        """keys: [(time, value), ...] sorted by time; ease applies between keys."""
        if t <= keys[0][0]: return keys[0][1]
        if t >= keys[-1][0]: return keys[-1][1]
        for (t0, v0), (t1, v1) in zip(keys, keys[1:]):
            if t0 <= t <= t1:
                return v0 + (v1 - v0) * ease((t - t0) / (t1 - t0))

    keys = [(0, 0), (1, 100), (2, 40)]
    for name, e in [("linear", linear), ("ease in/out", ease_in_out), ("ease out", ease_out), ("bezier(.42,0,.58,1)", bezier(.42, 0, .58, 1))]:
        print(f"{name:20}", [round(animate(keys, t, e), 1) for t in (0.25, 0.5, 1.0, 1.5)])

    # --- expressions: loopOut("cycle") and a seeded wiggle ----------------------
    def loop_cycle(keys, t, ease=ease_in_out):
        start, end = keys[0][0], keys[-1][0]
        return animate(keys, start + (t - start) % (end - start), ease)

    print("loopOut cycle:", [round(loop_cycle(keys, t), 1) for t in (0.5, 2.5, 4.5, 5.0)])

    def wiggle(freq, amp, t, seed=7):
        """smooth value noise: random values at 1/freq intervals, cosine-interpolated"""
        def at(i):
            return random.Random(seed * 1000 + i).uniform(-1, 1)
        x = t * freq
        i = math.floor(x); f = x - i
        f = (1 - math.cos(f * math.pi)) / 2
        return amp * (at(i) * (1 - f) + at(i + 1) * f)

    vals = [round(wiggle(2, 30, t / 10), 1) for t in range(0, 21, 2)]
    print("wiggle(2,30):", vals, "| stays within amp:", all(abs(v) <= 30 for v in vals))
    print("same seed repeats:", wiggle(2, 30, 0.37) == wiggle(2, 30, 0.37))
    ```

    Easing remaps normalised time before interpolation, so the same keyframes give different in-between values. Drop-frame timecode skips frame numbers (not real frames) to stay in step with 29.97 fps video. The wiggle uses seeded noise so it repeats, which is why After Effects' wiggle is deterministic per property. Verified by running the Python solution.

    ```
    import math

    # --- print production ------------------------------------------------------
    def with_bleed(w, h, bleed=3):
        return (w + 2 * bleed, h + 2 * bleed)

    def effective_ppi(pixels_w, placed_mm_w, scale_percent=100):
        return pixels_w / (placed_mm_w * scale_percent / 100 / 25.4)

    def tac(c, m, y, k):
        return c + m + y + k

    def naive_cmyk(r, g, b):
        """textbook RGB -> CMYK (no ICC profile); real conversions use profiles and rendering intents"""
        r, g, b = r / 255, g / 255, b / 255
        k = 1 - max(r, g, b)
        if k == 1: return (0, 0, 0, 100)
        return tuple(round(100 * v) for v in ((1 - r - k) / (1 - k), (1 - g - k) / (1 - k), (1 - b - k) / (1 - k), k))

    print("A5 trim with bleed:", with_bleed(148, 210), "| A4:", with_bleed(210, 297))
    for label, px, mm, sc in [("hero 3000px on 210mm", 3000, 210, 100), ("logo 600px on 60mm", 600, 60, 100), ("photo enlarged 150%", 2400, 100, 150)]:
        ppi = effective_ppi(px, mm, sc)
        print(f"{label}: {ppi:.0f} ppi -> {'ok for print' if ppi >= 250 else 'too soft for print' if ppi >= 150 else 'screen only'}")
    for name, ink in [("rich black", (60, 40, 40, 100)), ("heavy mix", (80, 70, 60, 90)), ("plain K", (0, 0, 0, 100))]:
        t = tac(*ink)
        print(f"{name:10} TAC {t}% {'over 300% limit' if t > 300 else 'within 300% limit'}")
    print("orange RGB(255,128,0) -> CMYK", naive_cmyk(255, 128, 0), "| black", naive_cmyk(0, 0, 0), "| mid grey", naive_cmyk(128, 128, 128))

    # --- colour contrast, audio gain and delivery size --------------------------
    def lin(c):
        c /= 255
        return c / 12.92 if c <= 0.04045 else ((c + 0.055) / 1.055) ** 2.4

    def lum(rgb):
        r, g, b = map(lin, rgb)
        return 0.2126 * r + 0.7152 * g + 0.0722 * b

    def contrast(a, b):
        la, lb = sorted((lum(a), lum(b)), reverse=True)
        return (la + 0.05) / (lb + 0.05)

    print("contrast white/#1a1a2e:", round(contrast((255, 255, 255), (0x1a, 0x1a, 0x2e)), 1), "| yellow on white:", round(contrast((255, 221, 0), (255, 255, 255)), 2))

    def gain_to_target(measured_lufs, target_lufs):
        db = target_lufs - measured_lufs
        return db, 10 ** (db / 20)

    db, ratio = gain_to_target(-20.5, -14)
    print(f"gain to reach -14 LUFS from -20.5: +{db:.1f} dB (x{ratio:.2f} amplitude)")

    def file_size_mb(video_mbps, audio_kbps, seconds):
        return (video_mbps * 1000 + audio_kbps) * seconds / 8 / 1000

    print("90 s social cut at 8 Mbps + 192 kbps audio:", round(file_size_mb(8, 192, 90), 1), "MB")
    print("4 min master at 50 Mbps + 320 kbps audio:", round(file_size_mb(50, 320, 240)), "MB")
    ```

    Effective ppi falls as an image is enlarged; TAC adds the four ink percentages; contrast uses relative luminance from linearised sRGB; a gain of +6.5 dB is an amplitude factor of about 2.1. File size is bitrate times duration divided by eight. Verified by running the Python solution.
