# Adobe Creative Cloud Mastery Path

A structured, module-wise Adobe Creative Cloud training program that takes you
from installing the Creative Cloud desktop app to producing a full multi-app
brand campaign — with step-by-step workflow instructions, keyboard-shortcut
cheat sheets, and a hands-on exercise in every module.

This track is **not** about coding — it's about learning the design and video
tools themselves: Photoshop, Illustrator, Premiere Pro, After Effects,
Lightroom, and InDesign, as real production workflows.

## How the program is organized

| Level | Focus | Modules |
|-------|-------|---------|
| [Level 1 · Entry](level-1/index.md) | Creative Cloud setup, Photoshop/Illustrator/Premiere/After Effects basics, cross-app Libraries | 9 topics + 1 project |
| [Level 2 · Intermediate](level-2/index.md) | Deeper Photoshop, Illustrator, and Premiere workflows | 9 topics + 1 project |
| [Level 3 · Advanced](level-3/index.md) | After Effects motion graphics, Lightroom, InDesign | 9 topics + 1 project |
| [Level 4 · Master](level-4/index.md) | Multi-app production pipelines, color management, client delivery | 9 topics + 1 capstone |

## How to use this site

- Work through each level in order — later modules assume earlier ones.
- Every topic page has numbered, step-by-step workflow instructions with menu
  paths and keyboard shortcuts spelled out — follow along inside the actual
  Adobe app.
- Each topic ends with a cheat-sheet table of the key tools and shortcuts
  covered, plus an **Exercise** to practice the workflow on your own file.
- Each level ends with a project that combines everything learned in that
  level.
- Use the search bar (top of the page) to jump straight to a topic.

Start here → [Level 1 · Entry](level-1/index.md)

## What you'll need

A [Creative Cloud](https://www.adobe.com/creativecloud.html) subscription
(or trial) that includes Photoshop, Illustrator, and Premiere Pro at minimum —
After Effects, Lightroom Classic, and InDesign are used starting in Level 1
Module 5 and Level 3. Any recent version of each app works; menu names are
stable across recent releases, though panel layouts can shift slightly
between versions.
