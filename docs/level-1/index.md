# Level 1 · Entry <span class="level-badge">Foundations</span>

Goal: get the Creative Cloud desktop app and your libraries set up, learn your
way around Photoshop, Illustrator, Premiere Pro, and After Effects, and ship a
small multi-app "brand kit" that ties everything together.

4. [Premiere Pro Basics](04-premiere-basics.md)

6. [Photoshop Compositing & Retouching](06-photoshop-compositing-retouching.md)

9. [Cross-App Creative Cloud Libraries Workflow](09-cross-app-libraries-workflow.md)
10. [Capstone Project — Brand Kit](10-capstone-brand-kit.md)

By the end of this level you'll be comfortable navigating the four core
Creative Cloud apps, know how to move assets between them with a shared
Library, and will have produced a small real deliverable: a logo, a poster,
and a short promo video that all share the same colors, type, and branding.
